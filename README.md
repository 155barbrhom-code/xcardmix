# مذاكرتي – بطاقات دراسية

تطبيق بطاقات دراسية ومراجعة متباعدة يعمل في المتصفح، ويمكن تثبيته على شاشة الهاتف.

## الملفات
- `index.html`: التطبيق نفسه
- `manifest.json`: بيانات التثبيت (الاسم والألوان والأيقونات)
- `sw.js`: يجعل التطبيق يعمل بدون إنترنت
- `icon-192.png` و `icon-512.png` و `apple-touch-icon.png`: الأيقونات

## ملاحظة عن البيانات
البيانات تُحفظ داخل المتصفح على كل جهاز. خذ نسخة احتياطية من داخل التطبيق من وقت لآخر.
